# RTT Assistant - 更新说明

## v2.0.0 更新内容 (最新)

### 架构重构

1. **Runtime目录分离**
   - 所有运行时文件从exe同级目录迁移到`runtime/`子目录
   - `runtime/dll/`：JLink_x64.dll、libusb-1.0.dll
   - `runtime/packs/`：CMSIS Pack文件
   - `runtime/venv/`：Python虚拟环境（PyOCD及依赖）
   - 配置文件迁移到`config/`目录
   - exe可完全独立，不污染用户目录

2. **独立Python虚拟环境**
   - PyOCD及所有依赖安装在`runtime/venv/`中
   - 不依赖系统Python环境
   - 首次使用可通过"帮助→依赖管理"安装依赖

### 新增功能

1. **支持ST-Link连接**
   - 使用NUCLEO-U575ZI-Q验证ST-Link RTT通讯
   - 使用RT-Thread Titan Board验证DAP-Link RTT通讯
   - 使用EK-RA8P1验证J-link ob RTT通讯

- 日志轮转：rtt_system.log和pyocd_diag.log使用RotatingFileHandler（5MB轮转）
- PyOCD目标索引：首次从pyocd_targets.txt快速加载（毫秒级），后台异步刷新
- 打包构建：build.py自动终止占用exe的进程，venv复制完整性验证

## v1.5.0 更新内容

### 新增功能

1. **PyOCD后端支持（DAP-Link/ST-Link）**
   - 新增PyOCD调试器后端，支持DAP-Link、ST-Link等CMSIS-DAP探针
   - 无需J-Link硬件即可使用RTT功能
   - 自动探测已连接的CMSIS-DAP探针
   - 支持从CMSIS Pack加载目标芯片定义

2. **CMSIS Pack管理**
   - 支持从本地`packs/`目录自动加载`.pack`文件
   - 用户可自行下载Pack放入`packs/`目录，点击"更新"按钮即可刷新
   - `pyocd.yaml`配置文件自动同步：刷新/连接时根据实际Pack文件自动生成
   - PyOCD目标列表缓存到`pyocd_targets.txt`，加快后续加载速度

3. **配置对话框步骤化**
   - 配置界面重新设计为5个清晰步骤：
     - 步骤1: 调试器选择（探针列表+刷新）
     - 步骤2: 连接方式（USB/TCP/IP）
     - 步骤3: 目标设备（J-Link/其他Link设备选择）
     - 步骤4: 接口设置（SWD/JTAG、速度、连接模式）
     - 步骤5: RTT控制块（搜索方式、Map文件等）
   - 每个步骤用QGroupBox分组，加粗标题+边框+编号，视觉清晰

4. **探针类型联动**
   - 选择DAP-Link/ST-Link时，"获取自动检测地址"按钮自动禁用（该功能依赖J-Link设备数据库）
   - Map文件搜索和"搜索_SEGGER_RTT"按钮对所有探针通用，不受影响
   - 切换探针时UI控件状态实时联动

5. **打包集成PyOCD**
   - PyOCD及其所有依赖（usb1、intelhex、pyelftools等）完整打包进exe
   - 打包后无需安装Python即可使用DAP-Link/ST-Link连接
   - `packs/`、`pyocd.yaml`、`pyocd_targets.txt`自动复制到exe同级目录

### 性能优化

- **配置弹窗延迟加载**：设备列表（14180个）和PyOCD目标列表延迟到对话框显示后异步加载，弹窗打开速度从~300ms优化至~10ms
- **PyOCD目标缓存**：优先从`pyocd_targets.txt`读取，避免每次`import pyocd`的开销

### 修复的问题

- 修复从Pack加载PyOCD目标失败：`[WinError 2] 系统找不到指定的文件`
  - 原因：`connection_dialog.py`硬编码`subprocess.run(['pyocd', ...])`，新电脑pyocd不在PATH
  - 修复：优先使用Python API加载，回退时使用`_find_pyocd_exe()`查找pyocd可执行文件

## v1.4.2 更新内容

### 新增功能

1. **RTT控制块搜索范围自动填充**
   - 在"配置-RTT控制块-搜索范围"后新增"获取自动检测地址"按钮
   - 点击后自动从devices.txt读取当前设备的RAMAddr和ram_size
   - 自动填充到搜索范围的起始地址和大小输入框
   - 无需手动查询设备RAM信息

2. **Map文件符号搜索功能**
   - 在"配置-RTT控制块"新增"Map文件搜索"分组框
   - **打开map文件**：选择map文件路径，自动保存到配置
   - **搜索_SEGGER_RTT**：解析map文件，自动提取RTT控制块地址并填入手动地址框
   - 支持GCC、IAR、Keil、GNU等编译器生成的map文件格式
   - 多编码支持（UTF-8、GBK、Latin-1）

3. **连接时自动更新RTT地址**
   - 当选择"手动地址"模式且配置了map文件路径时
   - 每次点击"连接"按钮会重新从map文件搜索最新RTT地址
   - 自动更新到配置并保存，无需手动刷新
   - MCU重新编译后RTT地址变化时自动适配

4. **DEBUG日志级别**
   - 系统日志新增DEBUG级别筛选选项
   - 性能追踪日志使用DEBUG级别（灰色显示）
   - 可在日志窗口筛选查看性能分析信息

### 性能优化

- **DeviceInfoService全局复用**：避免每次打开配置对话框重复解析1.9M的devices.txt文件
- 配置按钮响应时间从~3秒优化至~100ms

### UI改进

- "自动"按钮改名为"获取自动检测地址"
- Map文件搜索功能用GroupBox框起来，界面更清晰
- "打开"按钮改名为"打开map文件"

## v1.4.1 更新内容

### 新增功能

1. **设备完整信息读取与持久化**
   - 配置-更新时从JLink DLL读取每个设备的全部属性（name、manufacturer、Core、FlashSize、RAMSize、CoreId、FlashAddr、RAMAddr等），不再仅读取设备名称
   - 通过ctypes直接调用DLL的JLINKARM_DEVICE_GetInfo接口，无需连接J-Link硬件探针
   - devices.txt升级为v2结构化格式（`name|attr1=val1|attr2=val2|...`），向后兼容v1格式
   - 地址类字段（FlashAddr、RAMAddr、CoreId）以十六进制格式存储，提升可读性

2. **连接时设备信息日志打印**
   - 连接设备时，将该设备的全部信息以`[设备信息]`标签写入rtt_system.log系统日志
   - 日志格式：`[设备信息] name=STM32F407 | family=ST | core=0x0E0000FF | flash_size=1049104 | ...`
   - 设备信息不可用时标注"完整信息不可用"，打印失败不阻断连接流程

3. **版本号统一管理**
   - 版本号统一在`rtt_tool/__init__.py`的`__version__`变量中定义
   - 所有代码和打包脚本引用此变量，升级版本只需修改一处

### 技术变更

| 变更项 | v1.4 | v1.4.1 |
|--------|------|--------|
| 设备信息读取 | 仅name | 全部DLL属性 |
| devices.txt格式 | v1(仅名称) | v2(结构化键值对) |
| DLL调用方式 | jlink.open()+supported_device() | ctypes直接调用JLINKARM_DEVICE_GetInfo |
| 连接日志 | 无设备信息 | [设备信息]完整属性日志 |
| 版本号管理 | 多处硬编码 | __version__统一 |

## v1.4 更新内容

### 新增功能

1. **ANSI转义码染色**
   - 接收区支持解析SEGGER RTT定义的ANSI转义码（如`\x1B[2;31m`红色）
   - 默认关闭，通过工具菜单 → ANSI染色开关启用
   - 兼容RTT_CTRL_TEXT_RED等SEGGER RTT源码中定义的颜色宏

2. **关键字高亮**
   - 接收区支持关键字匹配高亮显示
   - 内置规则：ERROR/WARN/WARNING(黄色)/FAIL(红色)、OK/SUCCESS(绿色)、INFO(蓝色)
   - 支持自定义关键字和颜色配置
   - 默认开启，通过工具菜单 → 关键字高亮子菜单管理

3. **工具菜单**
   - 新增工具菜单，包含：字体设置、ANSI染色开关、关键字高亮子菜单
   - 关键字高亮子菜单包含启用开关和规则配置对话框

4. **RTT搜索日志增强**
   - 连接时自动记录memory zones信息（显示J-Link可访问的AP路径）
   - RTT初始化后记录Up/Down缓冲区数量和大小（延迟100ms确保状态准确）
   - 地址和范围模式连接失败时提供SEGGER知识库超链接提示

5. **RTT范围搜索模式**
   - 支持自研RTT控制块范围搜索（起始地址+大小），与SEGGER RTT Viewer一致
   - 搜索过程中记录日志，便于诊断多AP芯片（如瑞萨RZ系列）的RTT控制块定位问题

6. **设备列表从DLL更新**
   - 连接对话框新增"更新"按钮，可从J-Link DLL读取全部支持设备列表
   - 更新结果保存至devices.txt，下次启动自动加载

7. **J-Link DLL版本信息展示**
   - 关于页面显示J-Link DLL版本号和支持设备数量
   - 连接后状态栏显示J-Link序列号、硬件版本、固件版本

### 改进内容

1. **外部文件分离**
   - config.json、JLink_x64.dll、devices.txt不再打包进exe内部
   - 这3个文件与exe放在同一目录，方便用户修改配置和替换DLL
   - 首次运行自动在exe同目录生成config.json

2. **配置持久化增强**
   - 新增配置项：ansi_color_enabled、keyword_highlight_enabled、keyword_rules
   - 所有工具菜单开关状态自动保存到config.json，重启后恢复

3. **移除"跳过复位"功能**
   - 该功能在实际使用中效果不佳，已移除相关代码和UI

4. **DLL查找优先级调整**
   - 打包后优先从exe所在目录查找JLink_x64.dll，其次当前目录，最后JLink安装目录

### 技术变更

| 变更项 | 旧版本 | 新版本 |
