# RTT Assistant - 使用说明

## 基本使用流程

1. **启动程序**：双击 `RTT-Assistant v2.0.0.exe`
2. **点击连接**：点击工具栏"连接"按钮，打开配置对话框
3. **选择探针**：
   - J-Link：选择USB连接，程序自动探测已连接的J-Link探针
   - DAP-Link/ST-Link：选择"其他Link"，程序自动探测CMSIS-DAP探针
4. **选择目标芯片**：
   - J-Link：从设备列表选择（如STM32F407VE）
   - DAP-Link/ST-Link：从PyOCD目标列表选择（如r7ka8p1kf），如列表中没有可点击"下载Pack"获取
5. **配置参数**：接口选SWD，速度建议4000kHz
6. **点击确定**：连接成功后状态栏显示探针信息
7. **收发数据**：接收区自动显示RTT数据，发送区输入数据点击"发送"

## 探针配置详解

### J-Link

- 将`JLink_x64.dll`放在`runtime/dll/`目录下
- 支持USB和TCP/IP连接
- 支持序列号指定（多探针时区分）

### DAP-Link / ST-Link

- 无需额外驱动，USB连接即可
- 需要`runtime/packs/`目录下有对应芯片的`.pack`文件
- 首次使用需下载Pack：配置对话框中点击"下载Pack"，输入芯片型号（如STM32U575）

## CMSIS Pack管理

- **下载Pack**：配置对话框 → 步骤3目标设备 → "下载Pack"按钮 → 输入芯片型号
- **手动安装**：将`.pack`文件放入`runtime/packs/`目录，点击"更新"按钮刷新
- **刷新目标列表**：点击"更新"按钮，重新扫描所有Pack文件
- Pack目标优先于内置目标，同名目标以Pack为准

## RTT控制块搜索

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 自动检测 | J-Link自动搜索 | 大多数单核MCU |
| 手动地址 | 指定RTT控制块地址 | 自动检测失败时 |
| 搜索范围 | 指定RAM起始地址和大小 | 多AP芯片（如瑞萨RZ系列） |
| Map文件 | 解析map文件提取`_SEGGER_RTT`地址 | MCU重新编译后自动适配 |

## 数据收发

### 接收

- 自动显示RTT上行通道数据
- **时间戳**：勾选工具栏"时间戳"显示接收时间
- **HEX显示**：勾选"HEX显示"查看十六进制格式
- **ANSI染色**：工具菜单 → ANSI染色，解析SEGGER RTT颜色宏
- **关键字高亮**：工具菜单 → 关键字高亮，ERROR/WARN等关键字彩色显示

### 发送

- **字符串模式**：发送文本数据
- **HEX模式**：发送十六进制数据（如：01 02 03）
- 勾选"加换行"自动添加换行符
- 点击"发送"或按回车键发送

## 配置文件

`config/config.json`保存所有设置：
- 连接参数（探针、设备、接口、速度、RTT模式）
- 显示设置（时间戳、HEX、ANSI染色、关键字高亮）
- 窗口设置（大小、置顶、字体）

## 日志

- `log/rtt_system.log`：系统日志（5MB自动轮转，保留3个备份）
- `log/pyocd_diag.log`：PyOCD诊断日志（5MB自动轮转，保留2个备份）
- `log/rttdata_*.log`：RTT数据日志（每次连接新建）

## 故障排除

| 问题 | 解决方案 |
|------|---------|
| J-Link DLL找不到 | 将JLink_x64.dll放入runtime/dll/ |
| DAP-Link连接失败 | 确认packs/目录有对应.pack文件；确认探针USB已连接 |
| RTT初始化失败 | 确认MCU已移植RTT代码并初始化；尝试"搜索范围"模式 |
| 目标芯片列表为空 | 点击"更新"按钮刷新；或点击"下载Pack"下载对应Pack |
| 探针探测不到 | 确认USB连接；J-Link确认DLL正确；DAP-Link确认驱动正常 |
